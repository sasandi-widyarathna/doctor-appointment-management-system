# 🩺 Doctor Appointment Management System

A web-based Doctor Appointment Management System developed using **PHP** and **MySQL**. This platform enables patients to view doctor schedules and book appointments online, while allowing doctors and administrators to manage medical records and system operations efficiently.

## 🚀 Key Features
- 👤 **Patient Portal:** User registration, doctor search, and appointment booking.
- 👨‍⚕️ **Doctor Portal:** Manage patient appointments, diagnoses, and medical reports.
- 🛠️ **Admin Dashboard:** System settings, doctor/patient account management, and status updates.
- 💳 **Payment Records:** Track appointment payments and billing status.
- 📄 **Medical Reports:** Generate and view diagnoses and prescription records.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP
- **Database:** MySQL

## 🔧 Installation & Setup
1. Clone or download this repository.
2. Move the project folder into your local server directory (e.g., `htdocs` for XAMPP).
3. Open **phpMyAdmin** and create a new database named `southern_lanka_hms`.
4. Import the provided `database.sql` file into the newly created database.
5. Update your local database connection configuration if needed (e.g., `db.php` or `config.php`).
6. Run the application in your browser via `http://localhost/doctor-appointment-management-system/`.
